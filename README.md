# Carolina Hot Chicken — Demo

An original, high-impact restaurant demo built with Next.js, TypeScript, React, and a PostgreSQL-ready Drizzle schema.

## Run locally

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` when connecting a Vercel Postgres-compatible database.

## Demo features

- Responsive editorial hero and animated brand system
- Interactive heat selector
- Filterable menu with functioning demo cart
- Location, hours, catering, rewards, and social proof sections
- Accessible motion preferences and keyboard controls
- PostgreSQL schema for categories, menu items, and catering requests

All menu prices and promotional claims are demo content and must be confirmed by the restaurant before production use.
